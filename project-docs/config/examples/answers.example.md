# Confirmed facts and reusable answers

Template only. Copy to the configured private location. There are no approved candidate facts or answers in this file yet. Placeholder headings and illustrative instructions are never application answers.

## Confirmed facts

For each experience, education item, or project, record its real name/title, dates, responsibilities, exact supported figures, source, and user confirmation. Optional short fact IDs can help reference facts without repeating them. Do not invent facts to populate this template.

## Reusable answers

For each answer record:

- Exact question or narrowly defined question type.
- Confirmed answer text or value.
- Relevant context and limits on reuse.
- Supporting facts, where applicable.
- User confirmation and date.

Review applicability to the current form. A saved answer for one question does not authorize a different commitment.

## Values that need explicit setup

Work authorization/sponsorship, salary expectations, start date, travel/relocation/working-hours commitments, and optional demographic disclosure choices. Unknown means ask or leave blank if permitted. Do not convert null into a guessed yes/no.

Declarations, certifications, signatures, consents, and sensitive new questions require their actual wording to be understood and covered by explicit user direction. A profile name alone does not approve a signature.

## Narrative policy

The configured default is review_each. The user can choose draft_from_approved_facts for ordinary prose after role approval. Keep the confirmation of that choice. Neither mode permits fabrication, AI-prohibited answers, or accepting unfamiliar commitments.

## Writing preferences

Use the confirmed settings in preferences.json. Keep answers concise, first-person, and based on real details. Respect the question's length limit. Flag factual ambiguity instead of filling it with generic claims. Style checks are not an AI-detection evasion feature.
